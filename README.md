# EZH2 and immune checkpoints in IDH-wildtype glioblastoma

Reproducible analysis pipeline for:

> Siraj Ud Din, Sartaj Ud Din, Asif Ali Shah. *EZH2* expression is associated with *LAG3* and *PDCD1* independently of tumor proliferation in IDH-wildtype glioblastoma: a three-cohort analysis (submitted).

Archived version: [Zenodo DOI, version 1.1]

## Overview
Analysis of *EZH2* in three IDH-wildtype primary glioblastoma cohorts (TCGA n = 160; CGGA_325 n = 74; CGGA_693 n = 109): expression and PRC2/proliferation coupling, Cox survival models, confounder-adjusted (partial Spearman) correlations with eight immune checkpoint genes and fixed-effect meta-analysis (Fisher z, I2, random-effects sensitivity), ESTIMATE/MCP-counter microenvironment analyses, a cell-cycle sensitivity analysis (MSigDB Hallmark E2F + G2M), and single-cell summaries (TISCH2, Neftel et al. 2019, Smart-seq2).

## Data (public; not redistributed here)
| Data | Source | Place in |
|---|---|---|
| TCGA GBM expression (STAR, TPM) and clinical | GDC via TCGAbiolinks (downloaded by `00a`) | `share/` |
| CGGA mRNAseq_325 / mRNAseq_693 expression and clinical (manual download) | http://www.cgga.org.cn | `Data/geo/` |
| TISCH2 cell-type means for EZH2, LAG3, PDCD1 (GSE131928) | http://tisch.compbio.cn | `share/TISCH_*_heatmap.csv` |

## Requirements
R 4.6.0 with TCGAbiolinks 2.40.0, SummarizedExperiment, dplyr, stringr, survival 3.8-9, survminer 0.5.2, ggplot2 4.0.3, data.table, GSVA 2.6.3, msigdbr 26.1.1; estimate 1.0.13, immunedeconv 2.1.4 and MCPcounter 1.2.0 for the score files.

## Run
```r
setwd("path/to/project")                      # folder containing share/ and the scripts
source("00a_download_and_prepare_data.R")     # once: TCGA download and CGGA preparation
source("11_estimate_mcp_scores.R")            # once: ESTIMATE and MCP-counter scores
source("run_all.R")                           # scripts 01-07; writes results/run_log.txt
```

| Script | Content |
|---|---|
| 00_config_and_functions.R | settings and helper functions |
| 00a_download_and_prepare_data.R | download TCGA, prepare TCGA and CGGA input files |
| 11_estimate_mcp_scores.R | ESTIMATE and MCP-counter scores |
| 01_build_cohorts.R | cohort assembly |
| 02_expression_prc2_proliferation.R | expression, PRC2 and proliferation (Figure 1) |
| 03_survival.R | Kaplan-Meier and Cox models (Figure 2, Table 2) |
| 04_checkpoints_partial_correlation.R | checkpoint associations and meta-analysis (Figure 3) |
| 05_immune_landscape.R | ESTIMATE and MCP-counter associations (Supplementary Figure S1) |
| 06_single_cell_TISCH2.R | single-cell summaries, Smart-seq2 (Figure 4) |
| 07_proliferation_sensitivity.R | Hallmark cell-cycle sensitivity analysis (Supplementary Table S5) |

Outputs: `results/` (tables, logs) and `figures/`.
